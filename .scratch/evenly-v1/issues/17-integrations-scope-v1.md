# 17: Integration scope for v1

Type: grilling
Status: resolved
Blocked by: 07, 08, 01
Map: [Evenly v1 map](../map.md)

## Question

Which of Epic On-Call Finder, paging vendors, payroll exports, calendar feeds, public REST API ship in v1 vs later — driven by what the pilot actually needs to switch.

## Answer

Owner's answers in the stakeholder questionnaire, 2026-11-16 (https://claude.ai/artifact/1se9TniXGgXXBxQGK8yCMb):

- Day one: **personal calendar feeds** and an **on-call list for the hospital** (operator and paging).
- Payroll export and Epic On-Call Finder are **not** in v1.
